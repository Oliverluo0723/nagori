# look 第三批驗收：粒子發光系六個

日期：2026-11-12。分支 `milestone-4`。素材 KILL LOVE small + .mid，播放線 2:30，黑底發光主題。截圖同目錄 `2026-11-12-looks3-*.jpg`。

原則：粒子沒有累積狀態。每顆的位置都是「發射時刻（hit 或拍點或固定節奏的 tick）+ 年齡」算出來的，亂數用 `rngFor(seed, k)` 依發射索引取，所以同一首歌每一幀永遠一樣，拖播放線也對。共用工具在 `sheet.ts`：`ticksAlive`、`rngFor`、`bassAt(…, hold)`、`pitchRange`。

## 絲滑度

每幀畫圖時間（540 px、120 Hz）：黑底 噴泉 1.0 ms、露珠 0.4、萬花筒 0.8、彗星 0.9、星圖 0.3、流場 0.9；紙感全部 ≤ 0.9 ms。噴泉調亮加量後沒重量，估計 ≤ 2 ms。
